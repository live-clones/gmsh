# Graphics test cases, run by run.py.
#
# A case starts on an unindented line: its name, the files it opens (the
# first opened, the others merged; looked for next to this file, then among
# the files generate.py writes) and optionally N=<value>, passed to the
# DefineConstant[] of the .geo files. The indented lines that follow are its
# steps, in the .geo language: each is applied to the state left by the
# previous one, and drawn. A step can span several lines by ending them with
# a backslash. Every case is drawn once before its first step. (The steps
# are written out with a line break after every ';' and every For header,
# as the parser skips the body of a loop that starts on the line of its
# header.)
#
# View[] indices in views_o*.msh and polytopes_views.msh: 0, 1, 2 the scalar node, element and
# element node data, 3, 4, 5 the same for vectors and 6, 7, 8 for tensors.
# In lists.pos: 0 scalars, 1 vectors, 2 tensors, 3 strings, 4 the graph.
# Tags in OpenCASCADE models are taken from the model (e.g. s() = Surface{:};
# then s(0)): the kernel numbers the entities of its operations itself, and
# a missing tag is silently ignored.
